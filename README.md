# AI Motion Studio

Sistema experimental de edição automatizada usando:

- LangGraph
- Remotion
- GitHub
- Google Colab
- FFmpeg

Fluxo:

Narration
→ LangGraph
→ Scene Plan
→ Remotion
→ Render
→ MP4

Projeto desenvolvido para criação de motion graphics cinematográficos,
especialmente para documentários de astronomia.
